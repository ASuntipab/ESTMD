# รวมผล Questionnaire ใน Excel

## เป้าหมาย

เมื่อส่งออกโครงการ ให้แถวที่ประเมินจาก Questionnaire ปรากฏในชีต `PTTDigital_Manday` และรวม Man-day กับค่าใช้จ่ายในยอดสรุป แม้ผู้ใช้จะข้ามปุ่ม “สร้างรายการ” ใน wizard

## การออกแบบ

- คงชีต `Questionnaire` ไว้เป็นรายละเอียดคำตอบดิบ
- ขยายแบบจำลองสรุปกลางที่ใช้ทั้งหน้าสรุปและ Excel ให้เติมแถวชั่วคราวจากคำตอบที่มีจำนวนมากกว่า 0 และยังไม่มีรายการโครงการของ `activityId + complexity` คู่นั้น
- ใช้ `activity.groupName` เป็น phase; ถ้าไม่มี ให้ใช้ชื่อ activity ตามพฤติกรรมสร้างรายการปัจจุบัน
- ใช้ข้อความ detail จากคำตอบ หรือข้อความเริ่มต้นเดียวกับ `generateItemsFromAnswers`; ใช้หน่วยนับและระดับความซับซ้อนจาก activity/คำตอบ
- คำนวณค่าเริ่มต้นรายบทบาทจาก Standard Matrix, effective multiplier ของโครงการ และบทบาทที่รวมในโครงการ ตาม `standardManday`
- ใช้รายการโครงการที่บันทึกอยู่แล้วเป็นแหล่งหลักเมื่อมีคู่ `activityId + complexity` เดียวกัน เพื่อไม่ให้แถวที่กด “สร้างรายการ” แล้วนับซ้ำ และคงค่า MD ที่ผู้ใช้ปรับเองไว้
- สำหรับ activity ที่นับครั้งเดียวต่อโครงการ ให้ใช้ qty = 1 เช่นเดียวกับการสร้างรายการปัจจุบัน
- ใช้แบบจำลองสรุปเดียวกันต่อไป เพื่อให้ตัวเลขบนหน้าสรุปและใน workbook ตรงกัน; แถวชั่วคราวไม่ถูกบันทึกลงฐานข้อมูล

## สิทธิ์และข้อมูล

ไม่เปลี่ยนสิทธิ์ export, schema ฐานข้อมูล, questionnaire answers, หรือ action สำหรับสร้างรายการ. `getProjectDetail` จะให้ `buildSummary` เข้าถึงเซลล์ Standard Matrix ที่จำเป็นต่อการคำนวณคำตอบที่ยังไม่ถูก materialize เป็นรายการ.

## ขอบเขตที่ไม่รวม

- บันทึกแถวชั่วคราวลงฐานข้อมูลระหว่าง export
- ลบชีต `Questionnaire` หรือเปลี่ยนรูปแบบชื่อชีต `PTTDigital_Manday`
- แทนที่รายการโครงการที่บันทึกหรือค่า Man-day ที่ผู้ใช้ override

## เกณฑ์ยอมรับ

1. คำตอบที่มีจำนวนและยังไม่มีรายการ matching ปรากฏใน `PTTDigital_Manday` พร้อม phase, detail, activity/complexity label และ Man-day ต่อ role
2. คำตอบที่มีรายการ matching อยู่แล้วไม่ทำให้เกิดแถวหรือยอดซ้ำ; ข้อมูลและค่า override ของรายการเดิมคงอยู่
3. ยอด Man-day, ค่าใช้จ่าย และ Buffer สะท้อนแถว Questionnaire เพิ่มเพียงครั้งเดียวบนหน้าสรุปและใน Excel
4. การ export ไม่เปลี่ยนข้อมูลฐานข้อมูล และชีต `Questionnaire` ยังคงแสดงคำตอบตามเดิม
5. หน่วยนับ `ต่อโครงการ` ยังคูณเพียงหนึ่งครั้งตาม logic ปัจจุบัน

## การตรวจทาน

ตรวจแบบจำลอง summary, formula range ในชีตหลัก และ diff เพื่อยืนยันการจับคู่และการนับครั้งเดียว. ไม่เพิ่มหรือรันทดสอบอัตโนมัติตามข้อกำหนดของงานนี้.
